### 商品参数类问题

**Q1：联想EA230耳机的蓝牙版本是多少？支持哪些设备？**
 A：蓝牙版本为5.4，兼容播放器、平板、手机、电脑等设备，支持安卓、苹果、Windows 10等主流系统。

**Q2：单次充电能用多久？总续航时间是多少？**
 A：单耳听歌约5小时（正常音量），搭配充电仓总续航约24小时。充电时间约1.5小时（Type-C接口）。

**Q3：耳机重量和充电仓电池容量是多少？**
 A：单耳仅3.0g，充电仓电池容量为180mAh，耳机电池35mAh。
