### 招生录取类问题  

**Q1：湖南科技大学是几本？录取分数线大概是多少？** 
A：湖南科技大学是湖南省属重点本科高校，在大部分省份为**一本批次**招生。录取分数线因省份和专业不同有所差异，建议参考学校官网或所在省教育考试院公布的历年数据。  

**Q2：学校有哪些特色专业或优势学科？** 
A：学校在**矿业工程、安全工程、机械工程、计算机科学与技术、师范教育**等领域具有较强实力，其中“海牛Ⅱ号”深海钻机技术全球领先。具体可查看招生专业一览表。  

**Q3：转专业政策如何？难不难？** 
A：转专业通常要求**大一成绩排名前20%**，并通过目标学院的考核。各学院接收比例不超过5%，热门专业竞争较大，建议提前了解目标专业要求。

### 校园生活类问题  

**Q4：宿舍条件如何？有空调和热水吗？** 
A：南校区宿舍多为**四人间（1200元/年）**，无空调，热水需到公共澡堂刷卡使用。宿舍限电（白天600W，晚上220W），禁止使用大功率电器。  

**Q5：食堂怎么样？消费高吗？** 
A：南校区有3个食堂，支持校园卡或**“湖南科大APP”扫码支付**，价格适中，校外周边也有小吃店。  

**Q6：学校有门禁吗？晚上几点关门？** 
A：宿舍门禁采用**人脸识别闸机**，需“一人一闸”通行，具体关门时间因宿舍区不同，一般晚上11点左右。

### 学习与设施类问题  

**Q7：图书馆怎么样？学习氛围如何？** 
A：学校有**3个图书馆**（南校、北校、立言楼），藏书丰富，座位充足，学习氛围较好，考试周需提前占座。  

**Q8：大一能带电脑吗？学校有提供机房吗？** 
A：**学校不鼓励大一新生带电脑**，但未明确禁止。机房和电子阅览室可供使用，选课、作业等需求可满足。  

**Q9：学校有哪些校园活动或社团？** 
A：学校有各类社团、辩论赛、志愿活动等，可通过**“湖南科技大学企业号”**或学生会获取最新活动信息。

### 智慧校园与日常服务  

**Q10：校园网怎么办理？网速如何？** 
A：需下载**“湖南科大APP”**，绑定运营商账号后登录校园WiFi（iHNUST），网速稳定，适合学习和日常使用。  

**Q11：电费、水费如何充值？** 
A：宿舍电费可通过**企业微信或微信小程序**充值，水费需购买开水卡或使用校园卡。  

**Q12：报修宿舍或教室设备故障怎么操作？** 
A：可通过**“湖南科技大学后勤报修”微信公众号**提交问题，或联系楼长协调解决。

### 其他常见问题  

**Q13：学校交通方便吗？去市区远不远？** 
A：学校位于湘潭市雨湖区，**公交、打车便利**，去市区约20分钟车程，校内有观光车（1元/次）。  

**Q14：军训多久？有哪些注意事项？** 
A：新生军训一般**14天左右**（9月上旬），需准备防晒用品、舒适鞋垫等，具体安排入学后通知。  

**Q15：如何联系招生办或获取最新招生信息？** 
A：可通过**湖南科技大学本科招生网（zs.hnust.edu.cn）**或官方微信公众号查询，谨防虚假招生信息。  

如需更详细解答，可访问学校官网或相关平台获取最新资讯！
